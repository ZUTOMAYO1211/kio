# KIO — 키오스크 웹 시뮬레이터

실제 매장 키오스크의 UX를 웹으로 재현하고, 불편했던 부분을 개선한 개인 제작물.
빌드 도구 없이 **HTML / CSS / Vanilla JS** 로만 만들었고, 데이터는 전부 `localStorage` 에 남는다.

## 실행

정적 파일이라 서버 없이 `index.html` 을 열어도 대부분 동작하지만,
`file://` 에서는 브라우저에 따라 저장이 막히므로 로컬 서버 사용을 권장한다.

```bash
node .claude/serve.js
```

그 다음 `http://localhost:4173` 접속.

## 배포 (GitHub Pages)

저장소를 그대로 올리고 Settings › Pages 에서 브랜치 루트를 지정하면 끝이다.
빌드 단계가 없고 진입점이 `index.html` 이라 별도 설정이 필요 없다.

## 디자인 방향

실제 매장 키오스크(맥도날드 등)의 구조를 기준으로 삼았다. 잡지 레이아웃이 아니라 **역 안내판**에 가깝다 — 서서, 급하게, 도움 없이 읽는 공공 단말.

- **좌측 고정 카테고리 레일** — 스크롤해도 카테고리가 사라지지 않는다. 이름에서 아이콘을 자동으로 짐작해 붙인다
- **균일한 3열 그리드** — 카드 크기가 전부 같아 눈이 한 번에 훑는다. 비대칭 배치 없음
- **하단 고정 결제 바** — 어두운 잉크 바가 화면을 눌러 앉히고, 담긴 수량·금액·다음 행동을 항상 보여 준다
- 콘코스 그레이 바닥 · 흰 플레이트 · 보이는 괘선. 그림자는 실제로 떠 있는 요소에만 쓴다
- 본문은 Pretendard, **가격·열량·수량·주문번호만 Archivo Expanded** — 안내판 숫자의 성격을 숫자에만 준다
- 모션은 한 곳에만 쓴다: **합계 금액의 자리수 롤**. 금액이 바뀌면 바뀐 자릿수만 넘어간다

## 화면 크기

| 환경 | 동작 |
|---|---|
| 휴대폰 (세로) | 화면을 꽉 채운다. **메인 테스트 환경** |
| PC (가로) | 화면 중앙에 세로 9:16 키오스크 프레임으로 렌더링 |

기준 캔버스는 **1080 × 1920** 이고, 모든 치수는 이 좌표계에서 작성한 뒤
뷰포트에 맞춰 통째로 `transform: scale()` 된다.
따라서 CSS 의 `px` 는 언제나 "키오스크 픽셀"이지 기기 픽셀이 아니다.

최소 터치 영역은 168 키오스크 px 로, 390pt 폭 휴대폰에서 약 61 CSS px —
기획서의 60px 하한을 실제 테스트 기기에서 넘긴다. 큰 글씨 모드에서는 196px 로 커진다.

## 관리자 편집 모드

대기 화면의 **로고를 3초 안에 5번** 누르면 PIN 화면이 나온다. 초기 PIN 은 `0000`.

- 매장 설정 — 매장명 · 로고 · 시작 화면 이미지 · 테마 색상 · 통화 · PIN · 타임아웃
- 카테고리 — 추가 / 이름 변경 / 순서 / 표시 여부
- 메뉴 — 추가 · 수정 · 삭제, 사진(업로드 또는 URL), 가격, 열량, 품절, 대표 메뉴, 옵션 그룹 연결
- 옵션 그룹 — 단일 / 중복 선택, 옵션별 추가금
- 데이터 — 프리셋 5종 불러오기, 저장 용량, 전체 초기화
- 주문 로그 — 완료된 모의 주문 (최근 60건)

편집 내용은 입력하는 즉시 자동 저장된다.

## 적용한 차별점

1. **품절 메뉴 명시** — 목록에서 빼지 않는다. 사진을 회색 처리하고 그 위에 `품절` 배지를 얹어,
   메뉴가 사라져서 헤매는 상황을 막는다.
2. **큰 글씨 모드** — 토글 하나로 글씨와 터치 영역이 함께 커진다. 설정은 기기에 기억된다.
3. **무동작 타임아웃 안내** — 갑자기 초기화되지 않는다. 카운트다운 링과 함께
   "계속하기 / 처음으로" 를 먼저 묻는다. 계속하면 담아 둔 장바구니가 그대로 남는다.
4. **장바구니 상시 노출** — 하단 고정 바가 비어 있을 때도 사라지지 않고,
   현재 담긴 수량과 금액을 계속 보여 준다. 금액이 바뀌면 자리수가 넘어가며 갱신된다.

## 파일 구조

```
index.html          모든 화면의 뼈대
css/tokens.css      디자인 토큰 (색 · 타입 스케일 · 여백 · 반경 · 이징)
css/base.css        리셋, 키오스크 스테이지/스케일링, 필름 그레인, 화면 전환
css/components.css  버튼 · 카드 · 시트 · 다이얼로그 · 폼 (이중 베젤 구조)
css/customer.css    고객 흐름 (대기 · 유형 · 메뉴 · 상품 · 장바구니 · 결제 · 완료)
css/admin.css       편집 모드
js/presets.js       프리셋 5종 · 테마 · 썸네일 팔레트
js/store.js         상태 · localStorage · 장바구니 · 주문 · 이미지 리사이즈
js/ui.js            아이콘 · 썸네일 · 시트 · 다이얼로그 · 토스트
js/customer.js      고객 흐름 렌더링과 이벤트
js/admin.js         편집 모드 렌더링과 이벤트
js/app.js           스케일링 · 테마 · 라우팅 · 타임아웃 · 관리자 진입
```

## 범위 밖

실제 결제 연동, 서버 · DB, 로그인, POS 연동, 다중 매장 관리는 다루지 않는다.
결제 화면은 전부 모의이며 카드 정보를 입력받지 않는다.

보류 항목: 설정 Export / Import, 영화관 모드, 다국어, 사운드 피드백.
